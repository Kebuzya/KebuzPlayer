## Зачем

Для коллекции, которая лежит на диске: без аккаунта, без сети, без облака. Библиотека хранится в локальной базе SQLite, настройки - в одном JSON-файле. Полная приватность: плеер работает оффлайн. Единственный сетевой запрос - проверка новой версии на GitHub раз в сутки, её можно выключить в настройках.

Ключевые фичи - это решения проблем, с которыми я постоянно сталкивался в других аудиоплеерах: обложки, которые не выглядят одинаковыми серыми нотками, визуализатор, который можно поставить сразу в нескольких местах, и темы, в которых хочется сидеть.

Интерфейс на русском и английском: при первом запуске плеер выбирает русский на русской Windows и английский в остальных случаях, язык можно сменить в настройках в любой момент.

## Что умеет

### Обложки, нарисованные из звука

Трек без обложки не получает серую иконку с ноткой. Плеер разбирает сам звук - спектр, ритм, строение по сегментам - и рисует из этого картинку. Одна и та же музыка всегда даёт одно и то же изображение, поэтому библиотека остаётся узнаваемой. Любую обложку можно перегенерировать и прибавить или убавить хаоса.

### Визуализатор сразу в четырёх местах

Четырнадцать стилей, восемь цветовых режимов, и всё это настраивается отдельно для вкладки, полосы над библиотекой, оверлея и виджета на Главной. Частоту кадров выбираете сами: от 15 до 120 или по частоте монитора. F11 или одна кнопка разворачивают его на весь экран - на том мониторе, где стоит окно.

### Библиотека, которая не теряет нажитое

Несколько отслеживаемых папок, три вида отображения, сортировка, поиск, правка тегов и имени файла, удаление в корзину. Отключили папку - её треки просто спрятались. Перенесли папку на диске и указали новое место - за ней переехали прослушивания, обложки, плейлисты и история. При случайном удалении файла данные трека не стираются и дожидаются его восстановления.

![Библиотека](docs/library.gif)

### Оверлей, ведущий себя как системный OSD

Компактное окно поверх всех приложений, вызываемое по медиа-клавишам: что играет, прогресс, управление, громкость. Прячется само, как всплывающая громкость Windows, или фиксируется, если так удобнее.

![Оверлей](docs/overlay.gif)

### Остальное

- **Главная** - сетка виджетов, которую вы раскладываете сами: недавнее, часто слушаю, плейлисты, продолжить слушать, визуализатор.
- **Плейлисты** с ручным порядком, своим видом отображения и коллажем из обложек.
- **Проводник** - две панели с независимыми корнями, перенос файлов между ними и из Windows, воспроизведение прямо из папки.
- **Громкость по трекам** - ReplayGain из тегов плюс личная поправка, чтобы тихие записи не пропадали.
- **Семь тем**, каждая - полноценная палитра, а не переключатель светлого и тёмного.

## Установка

Берите архив из [Releases](../../releases):

| Файл | Что это |
| --- | --- |
| `KebuzPlayer-Setup-win-x64.exe` | Установщик. Маленький, сам подтянет .NET, если его нет. |
| `KebuzPlayer-win-x64-portable.zip` | Всё внутри, рантайм не нужен. Распаковал и запустил. |
| `KebuzPlayer-win-x64-lite.zip` | То же самое, но без рантайма: нужен установленный [.NET 8 Runtime](https://dotnet.microsoft.com/download/dotnet/8.0/runtime). Около 15 МБ. |

В обоих архивах рядом с программой лежит файл-маркер `kebuz.portable`: он держит базу и настройки в папке `Data` внутри папки программы, а не в вашем профиле. Удалите маркер - и плеер поведёт себя как установленный.

**Данные портативной версии.** Всё, что плеер помнит (библиотека, плейлисты, счётчики прослушиваний, обложки, настройки), лежит в папке `Data` внутри папки `KebuzPlayer`. Переносите или копируйте папку целиком - библиотека поедет вместе с ней. Чтобы обновиться, распакуйте новый архив поверх старой папки: `Data` в архиве нет, она останется на месте. Удаление `Data` сбрасывает плеер, сами музыкальные файлы не затрагиваются.

**SmartScreen.** Файлы пока не подписаны, поэтому при первом запуске Windows может предупредить: *Подробнее > Выполнить в любом случае*. Скачанный файл можно сверить по `checksums.txt`.

## Сборка из исходников

Нужен .NET 8 SDK.

```
dotnet build KebuzPlayer.sln
dotnet run --project KebuzPlayer
dotnet test KebuzPlayer.Core.Tests
```

## Где лежат данные

| Что | Где |
| --- | --- |
| База библиотеки | `%LOCALAPPDATA%\Kebuz\KebuzPlayer` |
| Настройки | `%APPDATA%\Kebuz\KebuzPlayer` |
| И то, и другое в портативном режиме | `Data\` рядом с программой |

## Устройство

| Проект | Что внутри |
| --- | --- |
| `KebuzPlayer.Core` | Никакого интерфейса: воспроизведение (NAudio), база (SQLite), теги (TagLibSharp), генерация обложек, анализ спектра. |
| `KebuzPlayer` | Сам интерфейс, на Avalonia. |
| `KebuzPlayer.Core.Tests` | Тесты на xUnit. |
